# Demo video

Drop the demo video here as `veli-demo.mp4`. The page picks it up automatically.

- H.264 MP4, no audio track needed (it always plays muted)
- Portrait 4:5 looks best, for example 1080 x 1350
- Keep it under 8 MB so mobile stays fast
- Until the file exists, visitors see the poster image `assets/web/demo-poster-640.webp`
